# SQL Retail Sales Analysis

## Project Overview

This project analyzes retail sales data using PostgreSQL. The objective is to clean the dataset, perform exploratory data analysis (EDA), and answer business-related questions using SQL.

## Objectives

- Clean the retail sales dataset
- Explore Customer Puchasing Patterns
- Analyse sales performance
- Practice SQL concepts using a real world dataset

## Dataset Information

The dataset contains retail sales transactions, including:

- Transaction ID
- Sale Date
- Sale Time
- Customer ID
- Gender
- Age
- Product Category
- Quantity
- Price per Unit
- cogs (Cost of Goods Sold)
- Total Sale

## Tools Used

- PostgreSQL
